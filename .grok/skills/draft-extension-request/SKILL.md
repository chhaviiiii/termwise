# draft-extension-request

Termwise skill. Use when the student asks, or when check-collisions finds 3+ major items in 48 hours.

## Draft rules

- Address the professor on file for the most flexible colliding item (project/paper over exam).
- Name the colliding dates and courses without oversharing personal details.
- Ask for a short, specific extension (usually 48 hours).
- Offer to share current progress.
- Always label the message DRAFT · NOT SENT.

Never send until the student writes "send it."
