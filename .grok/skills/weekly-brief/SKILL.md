# weekly-brief

Termwise routine. Schedule: every Sunday at 8:00 PM in the student's local timezone.

## Note must include

- What's due this coming week, by course (confirmed events only)
- Any deadline collisions in the next 2 weeks
- One thing the student should start early
- Estimated hours vs remembered weekly capacity
- Kept study blocks this week (skip suggested ones the student never kept)

## Safety

Show the draft first. Do not send unless the student said "send it" or auto-approved this routine. If Calendar/Gmail or Outlook are disconnected, post the note in chat and offer Fallback: mailto draft.
